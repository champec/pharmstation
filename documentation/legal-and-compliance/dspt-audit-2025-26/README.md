# DSPT 2024/25 — Independent Audit Submission Package

**Pharmstation — ODS D8W5S — IT Supplier**
**Prepared:** 30 April 2026
**Submission deadline:** 30 June 2026

## Purpose

This folder is a self-contained submission pack for the Independent Assessor: ToR, evidence index, draft report, management responses and submission checklist. The auditor reviews, adjusts if needed, signs, uploads to the DSPT portal under "Provide Audit details", then the SIRO publishes.

## Why "IT Supplier" scope (not CAF-aligned)

The CAF-aligned DSPT methodology applies in 2024/25 only to NHS Trusts (Acute, Foundation, Ambulance, Mental Health), ICBs, CSUs and DHSC ALBs. **IT Suppliers and Independent Providers designated as Operators of Essential Service** continue to use the existing DSPT with the **13 mandatory evidence items** scope set out in the NHSE guidance dated 12 May 2024. Pharmstation is an IT Supplier; the 13-item scope applies.
